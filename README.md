# AI_PACS_Pneumonia_Detection

## Features
- CNN-based pneumonia detection
- Flask dashboard
- X-ray upload system
- SQLite database
- Prediction confidence

## Technologies
- Python
- TensorFlow
- Flask
- OpenCV

https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia
